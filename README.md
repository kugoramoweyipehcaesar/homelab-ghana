# HomeLab GH - Ghana Home Lab Service

Fully operational Next.js 14 App Router medical lab booking system.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy on Render.com
1. Connect this repo
2. **Build Command**: `npm run build`
3. **Start Command**: `npm run start`
4. Add Environment Variables from `.env`

## Features
- Cart + localStorage persistence
- 4-step Booking Wizard
- Client Dashboard (protected)
- My Results with PDF / WhatsApp share
- Full Admin panel (edit prices live, upload results, change booking status)
- Toast notifications
- Fully responsive
